# AI module

This module will own AI decisions and later connect to Ollama.

- `api.py`: minimal FastAPI app; no application endpoints yet.
- `engine.py`: reserved for decision logic.
- `models.py`: reserved for request and response models.

Use Python 3.10+ and follow the virtual environment and launch commands in the [root README](../../README.md#run-locally). FastAPI's default documentation is available at <http://127.0.0.1:8000/docs>.
